# 2026 年 Claude Opus、GPT-5 系、Gemini Pro 在 Agentic 工具调用公开基准上的表现对比报告

## 核心结论

1. **三个模型的可比数据严重不足**：现有材料中，仅 Claude Opus 与 GPT-5 系列在 SWE-bench Verified 上有可引用的具体得分，Gemini Pro 在 SWE-bench Verified、τ-bench、BFCL 上均无任何有引用支持的具体得分 [unverified]。
2. **SWE-bench Verified 上 Claude Opus 领先**：Claude Opus 4.7 官方报告 87.6%，第三方排行榜显示 Opus 4.8 达 88.6%；GPT-5 系列最高为 GPT-5.3 Codex 的 85.0%（GPT-5.2 为 80%，GPT-5 High 约 55%）[cite:887][cite:888][cite:907][cite:908]。
3. **τ-bench 与 BFCL 数据几乎空白**：三个模型在 τ-bench 上均无得分数据；BFCL 仅在第三方横向评测中被间接提及（Claude 与 GPT 多轮类别聚集在 68–74% 区间），但未给出 Gemini Pro 的具体分数 [cite:902][unverified]。
4. **数据可靠性存疑**：SWE-bench Verified 得分多为厂商自报，OpenAI 已因数据污染问题于 2026 年初停止报告该基准分数，并建议改用 SWE-bench Pro [cite:908][cite:909]。
5. **评测条件差异无法回答**：现有材料未提供任何关于三个模型在工具集、提示格式、扩展思考/函数调用模式上的对比信息 [unverified]。

## 分述

### 一、Claude Opus 系列

**SWE-bench Verified（唯一有数据的基准）**

| 模型版本 | 得分 | 来源 |
|---|---|---|
| Claude Opus 4.8 | 88.6% | BenchLM.ai 第三方排行榜 [cite:887] |
| Claude Opus 4.7 (Adaptive) | 87.6% | Anthropic 官方系统卡（500 题子集，5 次试验平均，自适应思考最大努力配置）[cite:888]；BenchLM.ai [cite:887] |
| Claude Opus 4.7（Epoch 独立运行） | 83.47%（484 个验证任务中解决 404 个） | Epoch [cite:888] |
| Claude Opus 4.5 | 80.9% | BenchLM.ai [cite:887] |
| Claude Opus 4.6 | 80.8% / 80% | BenchLM.ai [cite:887]；另一来源 [cite:891] |

**τ-bench 与 BFCL**：检索到的证据中未包含 Claude Opus 在 τ-bench 或 BFCL 上的任何具体得分 [unverified]。

**其他 agentic 基准**：证据中提及 GPT-5.5 在 Terminal-Bench 2.0（82.7%）和 OSWorld-Verified（78.7%）上的成绩，但未提供 Claude Opus 在这些基准上的对应得分 [cite:889]。

**注意事项**：上述 SWE-bench Verified 得分大多来自提供商自报，而非独立复现；不同评估配置（如 scaffold、token 预算）可能导致结果不可直接比较 [cite:887][cite:888]。

**SWE-bench Verified**

- 2026 年 2 月 SWE-bench 官方（非自报）Bash Only 评测中，OpenAI 最高表现模型为 GPT-5.2（排名第 6），而 GPT-5.3-Codex 未参与该评测 [cite:910]。

**τ-bench 与 BFCL**：在提供的全部证据材料中，未出现任何关于 GPT-5 系列在 τ-bench 或 BFCL 上的得分数据 [unverified]。

### 三、Gemini Pro 系列

在所提供的证据材料中，未能找到 2026 年 Gemini Pro 在 SWE-bench Verified、τ-bench 或 BFCL 上的具体得分 [unverified]。相关材料仅涉及其他模型或不同基准：

- SWE-bench Verified 榜单前列为 Claude Opus 5（96%）、Claude Mythos 5（95.5%）等，未见 Gemini Pro 条目 [cite:893]。
- 2026 年 2 月的 SWE-bench 官方榜单提到 Gemini 3 Flash 进入前十，但未给出其具体分数，也未提及 Gemini Pro [cite:895]。
- Gemini 3.1 Pro 模型卡列出了 Terminal-Bench 2.0（68.5%）等 agentic 基准成绩，但未包含 SWE-bench Verified、τ-bench 或 BFCL 的分数 [cite:896]。

因此，针对 Gemini Pro 无法给出有引用支持的具体得分。

### 四、评测条件差异

现有证据材料无法回答该子问题。所有检索到的文档均未提及任何具体模型在 agentic 工具调用基准上的评测条件，也未提供三个模型之间在工具集、提示格式、扩展思考或函数调用模式上的对比信息。

可确认的相关背景信息（但不涉及具体模型对比）：
- 工具调用评测通常需要定义工具集（tools 字段，含 JSON Schema 描述）、对话上下文（messages）以及是否应触发工具的标签（should_call_tool）[cite:897]。
- 评测结果受服务商推理实现、后处理逻辑及提示工程差异的显著影响 [cite:897]。
- 函数调用模式与代码生成模式作为智能体动作层存在架构差异：函数调用由 JSON 模式描述预定义操作菜单，模型控制"做什么"，执行系统控制"如何做"；代码生成则由模型同时控制两者 [cite:900]。
- 在 Agentic 模型蒸馏中，需要真实仿真环境，离线学习容易出现 learner-sampler mismatch [cite:899]。
- 主流 agentic 基准包括 AgentBench（8 个环境）、AgentBoard、τ-bench、GAIA、WebArena 等 [cite:898][cite:901]。

### 五、第三方独立评测

2026 年存在第三方独立评测对三个模型的工具调用能力进行横向对比：

- **TURION.AI**：明确引用 Berkeley Function Calling Leaderboard (BFCL) v3 数据，对 GPT-5.4、Claude Opus 4.6、Gemini 3.1 Pro 进行横向对比，指出 Claude 和 GPT 模型在多轮类别中聚集在 68–74% 区间，而前沿三强并未主导该榜单 [cite:902]。
- **Artificial Analysis**：提供 Claude Opus 5 (Max) 与 Gemini 3.1 Pro Preview 的对比，包含 AutomationBench-AA 等 agent 相关评测指标 [cite:906]。
- **BenchLM**：提供 Claude Opus 5 与 Gemini 3.1 Pro 在 agentic work（工具使用、计算机使用、多步任务完成）方面的对比 [cite:905]。

关于 AgentBench 对这三个模型的横向对比，证据材料中未提及 [unverified]。
