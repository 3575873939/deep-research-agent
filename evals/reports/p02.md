# Tavily、Exa、SerpAPI 搜索 API 对比调研报告

## 核心结论

1. **定价模式差异显著**：Tavily 采用「免费额度 + 按量付费 + 套餐」混合模式，免费额度为 1,000 次/月（持续）[cite:947][cite:948]；Exa 采用按次/多因素计费，免费额度为一次性 2,000 次 [cite:947][cite:950]；SerpAPI 采用纯按月订阅套餐，免费额度仅 250 次/月 [cite:947][cite:951]。单价上，Exa 与 Tavily 约为每千次 $5 起，SerpAPI 约为每千次 $15，成本最高 [cite:947]。

2. **返回结构均为 JSON/字典格式，但字段丰富度不同**：Tavily 返回字典格式，核心字段为 results（含 title、content），支持 images 字段 [cite:952][cite:954]；Exa 返回 JSON，字段最为丰富，包含 results 数组（title、url、publishedDate、author、text、highlights、summary、entities 等）及 output、costDollars、searchTime 等顶层字段 [cite:944]；SerpAPI 返回 JSON，自然搜索结果位于 organic_results 数组（含 title、url、description、position、rating 等）[cite:939][cite:941]。

3. **语义搜索能力分化明显**：Exa 明确采用基于嵌入（embedding）的语义/向量检索，按网页「含义」分类 [cite:957][cite:958]；Tavily 定位为面向 LLM/RAG 的 AI 搜索聚合器，通过专有算法评分排序，但未被证实使用向量检索 [cite:952][cite:957]；SerpAPI 本质是搜索引擎结果 API，语义搜索能力缺乏证据支持 [cite:941][unverified]。

## 分述

### 一、定价方案对比

**Tavily**：采用混合模式。免费版每月提供 1,000 API credits，无需信用卡 [cite:948][cite:950]；按量付费（Pay As You Go）为 $0.008/credit [cite:948]；另有 Project 套餐（约 4,000 credits/月）及企业定制方案 [cite:948]。另有资料显示起始价为 $8 CPM，并提供基于项目的定价 [cite:953]。第三方基准测试显示其成本约为每 1,000 次搜索 $5–$8，免费额度为 1,000 次/月 [cite:947]。新账户起始即含 1,000 次免费请求，可在仪表盘监控用量并按需升级 [cite:954]。

**Exa**：采用按次/多因素计费。具体端点定价：Instant Search $4/1k 请求，Fast/Auto Search $7/1k 请求，Deep Search $12/1k 请求，Deep-Reasoning Search $15/1k 请求，Contents $1/1k 页，Monitors $15/1k 请求，Answer $5/1k 请求；基础价格包含最多 10 条结果，超出部分 $1/1k 请求/条 [cite:942]。层级包括 Starter（免费，每月 $10 额度）、Developer（PAYGO）、Enterprise（定制）[cite:942]。基准测试显示为每 1,000 次搜索 $5，免费额度为一次性 2,000 次 [cite:947]。新用户可获得 $10 免费额度，无需信用卡 [cite:950]。另有资料指出 Exa 使用多因素计费模式（按请求次数与搜索文档/爬取页面组合计费），对深度搜索提供额度并对结果和摘要额外收费，预算规划较复杂 [cite:949]。

**SerpAPI**：采用按月订阅套餐模式，按搜索量分级。入门价格为每月 25 美元，包含每月 1,000 次搜索，每小时 200 次吞吐量 [cite:938]；Starter 套餐 $25/月含 1,000 次搜索 [cite:951]；基准测试显示其起价 $75/月含 5,000 次搜索，折合每 1,000 次 $15（即 $0.015/次）[cite:947]。免费额度为 250 次/月 [cite:947]。

**三者对比小结**：免费额度方面，Tavily 为 1,000 次/月（持续），Exa 为 2,000 次一次性，SerpAPI 为 250 次/月 [cite:947]。单价方面，Exa 与 Tavily 约为每千次 $5 起，SerpAPI 约为每千次 $15，成本最高 [cite:947]。计费结构上，SerpAPI 为纯订阅套餐，Tavily 为免费+按量+套餐混合，Exa 为按次/多因素计费 [cite:948][cite:949][cite:950][cite:951]。

### 二、返回结构对比

**Tavily**：search 方法执行搜索查询并返回结构化的字典（dictionary）格式结果 [cite:952]。响应为字典，关键字段为 results，每个结果项包含 title（标题）和 content（内容）等字段 [cite:954]。通过 include_images 参数可在搜索结果中包含图片，图片位于响应的 images 字段中 [cite:954]。搜索结果以结构化方式返回，便于直接传递给 LLM 作为上下文 [cite:952]。

**Exa**：返回 JSON 格式，包含 results 数组（每个结果含 title、url、publishedDate、author、id、image、favicon、text、highlights、highlightScores、summary、subpages、entities、extras 等字段），以及 output（含 content 和 grounding）、requestId、costDollars、searchTime、resolvedSearchType、context 等顶层字段 [cite:944]。

**SerpAPI**：返回 JSON 格式的结构化数据 [cite:941]，自然搜索结果通常放在 organic_results 数组中 [cite:939]，字段包括 title、url、description、position、rating 等 [cite:939]。

### 三、语义搜索能力对比

**向量检索/语义检索机制**：Exa 明确采用基于嵌入（embedding）的语义搜索，其专有索引按网页「含义」而非文字内容分类，属于语义/向量检索路线 [cite:957][cite:958]。Tavily 则被描述为「混合 AI 搜索聚合器」，整合自有抓取工具与第三方数据聚合，并未被证实使用向量检索 [cite:957]；其定位是面向 LLM/AI 代理的专用搜索引擎，提供实时、准确信息 [cite:960]。SerpAPI 的语义/向量检索能力在现有证据中无任何说明 [unverified]。

**自然语言查询**：Exa 支持处理细致查询的语义搜索，并提供 search_and_contents 等接口，可自动判定关键字或嵌入式搜索类型 [cite:958]。Tavily 的搜索接口支持自然语言 query，并可返回答案（include_answer）、相关性分数等 [cite:960]。SerpAPI 的自然语言查询能力无证据支持 [unverified]。

**结果相关性排序**：Tavily 的搜索返回结果中包含 score（相关性分数）字段，可用于相关性排序 [cite:960]。Exa 因按「意义」搜索，常返回「概念相似」但实际无关的结果，即相关性存在偏差 [cite:957]。在实测对比中，Exa 在技术检索上表现最优（结果权威且新），Tavily 为中等（整合多源信息），而 Brave 相关性一般 [cite:959]。SerpAPI 的相关性排序表现无证据支持 [unverified]。

**综合定位差异**：Exa 专为 AI 优化、支持复杂语义检索，适合高质量数据需求 [cite:959]；Tavily 面向 RAG 与 AI 代理工作流，强调减少幻觉的相关结果 [cite:958]，但存在提取噪音、大规模延迟、失效链接及 SPA 处理困难等局限 [cite:957]。SerpAPI 在语义搜索三个维度上均缺乏可证实信息 [unverified]。

### 四、Tavily 语义搜索能力补充

Tavily Search API 专为 LLM 优化，针对 RAG（检索增强生成）场景进行了优化，可在单次 API 调用中完成搜索、抓取、过滤和信息提取 [cite:952]。它通过专有算法对结果进行评分和排名，确保返回最相关的内容，并保证实时响应和高效的信息提取 [cite:952]。该 API 支持可调节的搜索深度、领域管理、HTML 内容解析，以及包含或排除特定域名，以确保搜索结果的相关性和精准性 [cite:952]。此外，Tavily 支持文本和图片搜索，具有多种应用场景的通用性 [cite:954]。

### 五、Exa 语义搜索能力补充

Exa 基于嵌入（embeddings）的神经搜索，理解语义意图而非仅关键词匹配，支持相似性搜索、内容抓取、大规模结果（一次搜索可获取多达 100 万条结果）、最新资讯抓取、强大过滤器（按域名、日期范围、数据类别）[cite:943][cite:946]。Exa 在 FRAMES、Tip-of-Tongue、Seal0 等检索基准上领先，支持多种搜索垂直领域（公司、人物、代码等）[cite:945]。

## 未验证结论

1. SerpAPI 并未明确提及具备语义搜索能力 [unverified]。
2. SerpAPI 的语义/向量检索能力在现有证据中无任何说明 [unverified]。
3. SerpAPI 的自然语言查询能力无证据支持 [unverified]。
4. SerpAPI 的相关性排序表现无证据支持 [unverified]。
5. SerpAPI 在语义搜索三个维度（向量检索、自然语言查询、结果相关性排序）上均缺乏可证实信息 [unverified]。
