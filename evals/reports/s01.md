# ModelScope openai_compatible 接口模型支持与限流策略调研报告

## 核心结论

1. **模型支持**：根据第三方接入指南，ModelScope 的 OpenAI 兼容端点（`https://api-inference.modelscope.cn/v1`）推荐支持 DeepSeek 系列、Qwen 系列，并提及 GLM-5.1、Yi 等主流开源模型；模型 ID 格式为"组织/模型名"，完整列表需在 ModelScope 模型库中筛选"API 推理"查看 [cite:359]。但该指南为第三方项目文档，其中具体模型名称的准确性未经官方交叉验证 [unverified]。

2. **限流策略**：现有材料中**缺乏 ModelScope 官方对 openai_compatible 接口限流规则的明确说明**。可确认的是平台存在 API 调用频率限制，需合理设置调用频率以避免触发限流 [cite:360]；用户实测反馈存在"显示 2000 次/天免费额度、但约 200–500 次即出现 429 限流"的现象 [cite:365]。

3. **差异化限流**：关于限流是否因**模型系列**、**用户等级/API Key 类型**、**请求类型（流式/非流式）** 而不同，现有材料均**无法证实**，相关结论均标注为 [unverified]。

## 分述

### 一、支持的模型系列

根据 ModelScope 接入指南，OpenAI 兼容端点当前推荐支持的模型系列包括 [cite:359]：

- **DeepSeek 系列**：如 `deepseek-ai/DeepSeek-V4-Pro`、`deepseek-ai/DeepSeek-R1` [cite:359]
- **Qwen 系列**：如 `Qwen/Qwen3-Coder-30B-A3B-Instruct`、`Qwen/Qwen3-235B-A22B-Instruct` [cite:359]
- **其他主流开源模型**：文档还提及 GLM-5.1、Yi 等均可用 [cite:359]

**使用要点**：
- 完整模型列表需在 ModelScope 模型库中筛选"API 推理"查看 [cite:359]
- 模型 ID 格式为"组织/模型名" [cite:359]

> ⚠️ 注意：上述指南为第三方项目文档，其列举的模型名称（如 DeepSeek-V4-Pro、GLM-5.1）的准确性未经官方来源交叉验证 [unverified]。

### 二、限流策略现状

现有证据材料中**缺乏 ModelScope 官方对 openai_compatible 接口限流规则的明确说明**。可确认的信息如下：

- **平台存在频率限制**：ModelScope 平台存在 API 调用频率限制，用户需根据阿里云的限制合理设置调用频率以避免触发限流 [cite:360]。
- **实测限流现象**：有用户反馈平台显示每天有 2000 次 API 免费额度，但在约 200–500 次调用时即出现 429 限流错误（Request limit exceeded）[cite:365]。
- **模型规格差异现象**：有用户提到不同模型规格的限流表现不同（如 480B 模型受限而 30B 模型可用）[cite:365]。

**未明确事项**：限流的具体维度（如 RPM/TPM/RPS 等）以及 openai_compatible 接口是否与 DashScope 兼容模式采用相同限流机制，现有材料未提供明确说明 [unverified]。

### 三、限流是否因模型系列不同而不同

现有证据材料**无法证实** ModelScope 的 openai_compatible 接口存在按模型系列差异化的限流策略。

检索到的限流相关文档均来自**其他平台**，而非 ModelScope 本身：

- 阿里云 API 网关的 `AiTokenRateLimit` 策略支持按模型名称（`limitType=Model`）设置差异化限流阈值，可针对不同模型设置独立限额 [cite:358]。
- 百炼（Model Studio）平台的限流按主账号维度、模型独立计算，各模型的限流条件不同 [cite:370]。

此外，仅检索到一条关于 EvalScope 支持自定义模型接口格式的 GitHub issue [cite:366]，与限流策略无关。

**结论**：ModelScope openai_compatible 接口的限流策略是否因模型系列不同而不同，[unverified]。

### 四、限流是否因用户等级或 API Key 类型不同而不同

现有证据材料**无法证实** ModelScope openai_compatible 接口的限流策略会因用户等级或 API Key 类型不同而有所差异。

- citation 361 仅泛泛提及"根据阿里云的限制，合理设置调用频率，避免达到限流条件"，并建议"调整调用频率或申请更高的限流额度"，但未说明限流是否按用户等级或 Key 类型区分 [cite:361]。
- citation 363 讨论的是阿里云百炼（Model Studio）的 OpenAI 兼容接口，其中提到 API Key 按地域绑定、跨地域调用会被鉴权拒绝，属于**地域维度**的限制，而非用户等级或 Key 类型维度的限流差异 [cite:363]。
- citation 369 为 Kimi API 的 OpenAI 兼容性说明，与 ModelScope 无关 [cite:369]。

**结论**：关于限流策略是否因用户等级或 API Key 类型不同而不同，[unverified]。

### 五、限流是否因请求类型（流式/非流式）不同而不同

现有证据材料中**未包含任何关于 ModelScope openai_compatible 接口限流策略的信息**，无法证实其限流策略是否因请求类型（流式/非流式）不同而存在差异 [unverified]。

相关材料仅涉及流式与非流式输出的一般性技术对比（如传输协议、资源占用、计费规则等），例如有资料指出流式输出与非流式调用的计费规则完全相同 [cite:367]，但均未提及 ModelScope 平台或任何限流（rate limit）策略 [unverified]。
