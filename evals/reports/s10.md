# 2026 年国内大模型 API 免费额度政策调研报告

## 核心结论

- **阿里云百炼**：面向首次开通用户自动发放"新人专属免费额度"，无需手动领取、无需实名认证；仅限华北2（北京）地域，有效期 90 天，每个模型通常 100 万 Token，输入输出共用，额度独立不互通 [cite:482][cite:484]。
- **DeepSeek**：新账户注册即赠送 500 万 token 余额，可用于任意 DeepSeek 模型，自注册日起 30 天内有效，过期清零 [cite:490]。
- **智谱 AI**：新用户注册赠送 2000 万 Token；GLM-4-Flash、GLM-Z1-Flash 等 Flash 系列模型完全永久免费（限 30 并发）；GLM-4-Air 提供每月自动重置的 100 万 Tokens 免费额度 [cite:481][cite:483]。
- **月之暗面（Kimi）**：Kimi K2 可通过 App 与浏览器界面免费使用，大规模部署按量收费；Kimi K3 计划于 2026 年 7 月底前向全球开发者免费开放。但**具体的 API 免费额度数值（如每月免费 token 数、调用次数上限）在现有材料中缺失** [cite:480][cite:486][cite:487]。

## 分述

### 一、阿里云百炼

**发放方式与门槛**
- 免费额度为面向首次开通用户自动发放的"新人专属免费额度"，无需手动领取或购买任何产品，也无需实名认证即可获取和使用 [cite:484]。

**地域与有效期**
- 免费额度仅限华北2（北京）地域的模型享有，其他地域无免费额度 [cite:482][cite:484]。
- 有效期为 90 天，自开通阿里云百炼、模型发布或模型申请通过之日起计算（以较晚者为准）；2025 年 9 月 8 日 11 点前已开通的用户有效期可能不足 90 天 [cite:484]。

**额度结构与使用规则**
- 每个模型（含同一模型的不同快照版本）拥有各自独立的免费额度，通常为 100 万 Token，额度相互独立、不互通、不共享，不能跨模型合并或转移使用 [cite:484]。
- 免费额度为输入 Token 和输出 Token 共用的总额度，不单独区分输入或输出 [cite:484]。
- 仅抵扣模型实时推理（调用）产生的费用；Batch 调用、模型调优、模型部署、自定义模型、PAI-DSW、OSS 存储及请求费用不支持用免费额度抵扣 [cite:484]。
- 主账号与其 RAM 子账号共享免费额度 [cite:484]。

**额度用尽与过期处理**
- 未认证用户额度用完后无法继续调用，需完成认证并充值后方能继续按量付费；已认证用户自动转为按量付费，可提前开启"免费额度用完即停"功能避免意外扣费 [cite:484]。
- 免费额度过期后自动失效，不支持补发、延期或重置，同一实名认证主体下重新注册账号无法再次领取 [cite:484]。
- 余量降至 20% 或完全耗尽时，系统会通过短信、站内信、邮件发送通知 [cite:484]。

### 二、DeepSeek

**免费额度**
- 新账户注册即赠送 500 万 token 余额，可用于任意 DeepSeek 模型，该额度自注册日起 30 天内有效，过期未用完会清零 [cite:490]。

**相关价格信息（非免费额度，供参考）**
- DeepSeek V4 Pro 在 2026 年 5 月 31 日 15:59 UTC 之前提供 75% 折扣价（$0.435/M 输入、$0.87/M 输出，按 cache miss 计）[cite:490]。
- V4 Flash 的价格为 $0.14/M 输入、$0.28/M 输出 [cite:490]。
- 有资料提及 DeepSeek 已于 2026 年 8 月 16 日将 V4 全系改为峰谷计价，上述价格为调整前的快照 [cite:490]。

**通过第三方平台调用**
- 通过第三方聚合平台（如阿里云百炼）也可调用 DeepSeek 系列模型，该平台为新用户提供每个模型 100 万 Tokens 的免费额度，有效期 3 个月 [cite:491]。

### 三、智谱 AI

**新用户与免费模型**
- 新用户注册即赠送 2000 万 Token [cite:481]。
- GLM-4-Flash、GLM-Z1-Flash 等 Flash 系列模型完全永久免费，无 Token 限制，仅限并发数（所有模型限 30 并发）[cite:481]。

**周期性免费额度**
- GLM-4-Air 提供每月自动重置的免费额度（每月 100 万 Tokens，但有 RPM/TPM 限制）[cite:483]。

**高级模型与风险提示**
- GLM-5、GLM-5.1 等高级模型不免费或免费额度有限，使用前需确认 [cite:483]。
- 智谱支持 MCP 协议，便于 Agent 开发 [cite:483]。
- 智谱 2026 年已三次上调 API 价格，免费策略可能随时收紧，建议以官网最新公告为准 [cite:483]。

### 四、月之暗面（Moonshot AI / Kimi）

**免费访问方式**
- 根据月之暗面官网信息，Kimi K2 开放使用者免费通过 App 与浏览器界面存取，不同于 ChatGPT 和 Claude Opus 需订阅付费 [cite:480][cite:486]。

**大规模部署收费**
- 若要进行大规模部署，Kimi K2 仅收取每百万输入 Token 0.15 美元、输出 Token 2.5 美元的费用 [cite:480][cite:486]。

**开发者使用限制**
- Moonshot 表示开发者可自由使用 K2 模型，唯一限制是若商业产品月活超过一亿人，或营收达 2,000 万美元，需于界面明示「Kimi K2」字样 [cite:480][cite:486]。

**2026 年新模型免费计划**
- Kimi K3 计划于 2026 年 7 月底前向全球开发者免费开放 [cite:487]。

## 未验证结论

- 月之暗面（Kimi）K2 的免费政策来自官网转述，K3 的免费开放计划为媒体报道，均未提供具体的 API 免费额度（如每月免费 token 数、调用次数上限等）细节 [unverified]。
- 关于月之暗面 2026 年 API 免费额度的具体数值（如免费 token 配额、限流规则等），现有证据材料中未包含相关信息 [unverified]。
