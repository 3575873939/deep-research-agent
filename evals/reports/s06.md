# MCP 协议版本演进与生态主流 Server 调研报告

## 核心结论

- MCP（Model Context Protocol）由 Anthropic 于 2024 年 11 月发布，是一个用于标准化 LLM 与外部工具、系统和数据源集成的开放标准与开源框架 [cite:436]。
- 首版规范（2024-11-05）确立了 Prompts、Resources、Tools 三类服务端特性与 Roots、Sampling 两类客户端特性，基于 JSON-RPC 2.0，采用 host-client-server 架构，支持 STDIO 与 SSE over HTTP 两种传输层 [cite:437][cite:438]。
- 2025-03-26 版本相比首版新增了多项能力：OAuth 2.1 授权、Streamable HTTP 传输、JSON-RPC 批处理强制支持、工具注解、音频数据支持、completions 能力、ProgressNotification 的 message 字段等 [cite:429][cite:440]。
- 2025 年 11 月又发布了新规范版本，涉及任务工作流、授权、扩展、采样等主题 [cite:433]。
- 生态中的主流 server 分为官方参考实现（如 Everything、Fetch、Filesystem、Git、Memory 等）与社区/第三方实现（如 GitHub、Slack、Google Drive、PostgreSQL、Redis、Notion、Stripe 等）[cite:435][cite:434]。

## 分述

### 一、2024 年首版规范的核心能力与消息类型

MCP 首版规范（2024-11-05 版本）的核心能力包括：

**服务端特性（三类）：**
- **Prompts（提示模板）**：服务器提供的可复用参数化模板，用于结构化 AI 工作流，对应 `prompts/list`、`prompts/get` [cite:438]。
- **Resources（资源）**：用于向 AI 暴露数据，以自定义 URI 标识，可为静态或动态，对应 `resources/list`、`resources/read` [cite:438]。
- **Tools（工具）**：允许 AI 执行动作或计算，模型发送符合工具 JSON Schema 的 JSON 载荷，服务器执行逻辑并返回结果，对应 `tools/list`、`tools/call` [cite:438]。

**客户端特性（两类）：**
- **Roots** [cite:437]
- **Sampling** [cite:437]

**协议基础：**
- 基于 JSON-RPC 2.0，采用 host-client-server 架构 [cite:438]。
- 支持 STDIO（本地）与 SSE over HTTP（远程）两种传输层 [cite:438]。
- 包含基础协议、生命周期、版本管理及 Ping、Cancellation、Progress 等实用工具 [cite:437]。
- 包含 Completion、Logging、Pagination 等服务端实用功能 [cite:437]。

### 二、当前版本相比首版的新增能力

**2025-03-26 版本的主要更新：**
- 授权方式从 OAuth 2.0 升级到 OAuth 2.1 [cite:429]。
- 传输通道用 Streamable HTTP 替换旧版的 HTTP+SSE [cite:429][cite:440]。
- 正式在协议层面强制支持 JSON-RPC 批处理（Batching）[cite:429]。
- 新增工具注解（Tool Annotations），补充工具的行为与展示元数据 [cite:429]。
- 新增对音频数据的支持，强化多模态能力 [cite:429]。
- 新增 completions 能力，显式声明对参数自动补全的支持 [cite:429]。
- ProgressNotification 新增 message 字段 [cite:429]。
- 采样（Sampling）能力允许 MCP 服务器向客户端 LLM 请求完成，增加了协议的双向性 [cite:440]。

**2025 年 11 月版本：**
- 发布了新规范版本，涉及任务工作流、授权、扩展、采样等主题 [cite:433]。

### 三、生态中的主流 MCP Server

**官方 modelcontextprotocol/servers 仓库中仍在维护的参考 server：**
- Everything、Fetch、Filesystem、Git、Memory、Sequential Thinking、Time [cite:435]。

**该仓库中已归档（archived）的参考 server：**
- AWS KB Retrieval、Brave Search（已被官方 @brave/brave-search-mcp-server 取代）、EverArt、GitHub、GitLab、Google Drive、Google Maps、PostgreSQL、Puppeteer、Redis、Sentry、Slack（现由 Zencoder 维护）、SQLite [cite:435]。

**社区整理的 2025 年常用 MCP server 列表：**
- File System、GitHub、Slack、Google Maps、Docker、Brave、PostgreSQL、Google Drive、Redis、Notion、Stripe、Perplexity [cite:434]。

**聚合资源：**
- 社区还维护有 awesome-mcp-servers 这类聚合列表 [cite:431]。

### 四、维护组织与客户端支持

**维护组织：**
- Anthropic 是 MCP 协议的提出者和主要推动者，并预先构建了针对 Google Drive、Slack、GitHub、Git、Postgres 和 Puppeteer 等热门企业系统的 MCP 服务器 [cite:430]。
- Block 和 Apollo 是早期尝鲜者；Zed、Replit、Codeium 和 Sourcegraph 等开发工具公司正在与 MCP 合作 [cite:430]。

**客户端支持情况：**
- **Claude Desktop**：支持所有 MCP 功能（资源、提示、工具），是功能最完整的客户端 [cite:432]。
- **Cursor**：支持工具功能 [cite:432]，且被明确列为支持 MCP Server 接入的客户端 [cite:430]。
- **Continue**：支持所有 MCP 功能（资源、提示、工具）[cite:432]。
- **Zed**：支持提示功能，以斜杠命令形式出现 [cite:432]。
- **Sourcegraph Cody**：通过 OpenCTX 支持资源 [cite:432]。
- **Firebase Genkit**：支持资源列表和查找，以及提示和工具 [cite:432]。
- **GenAIScript**：支持工具 [cite:432]。
