# DeepSeek 官方 API、ModelScope、阿里云百炼三通道 Qwen/DeepSeek 模型调用对比报告

## 核心结论

1. **DeepSeek 官方 API** 对 DeepSeek 系列模型采用"空闲/高峰"分时定价，空闲时段价格为高峰时段的一半，并以**并发数**（而非 RPM/TPM）作为核心限流维度：deepseek-flash 并发限制 2500，deepseek-v4-pro 并发限制 500 [cite:1193][cite:1195][cite:1191]。
2. **阿里云百炼** 对 Qwen 系列模型采用按量计费 + 阶梯定价，限流以 **RPM/TPM/RPS/TPS/增速** 多维度表述，按主账号维度合并计算，超限返回 429（免费额度耗尽返回 403）[cite:1207][cite:1208][cite:1209][cite:1211]。
3. **ModelScope** 的定价与限流规则在现有证据材料中**完全缺失**，无法给出任何有引用支持的结论 [unverified]。
4. 在**相同模型**（如 Qwen2.5-72B、DeepSeek-V3）下对三者进行每百万 token 成本或限流阈值的直接对比，**现有证据不足以量化** [unverified]。

## 分述

### 一、DeepSeek 官方 API（DeepSeek 系列模型）

#### 1.1 定价（每百万 tokens）

| 模型 | 计费项 | 空闲时段 | 高峰时段 |
|---|---|---|---|
| deepseek-flash（DeepSeek-V4.1-Flash） | 缓存命中输入 | $0.003 / 0.02元 | $0.006 / 0.04元 |
| | 缓存未命中输入 | $0.15 / 1元 | $0.3 / 2元 |
| | 输出 | $0.6 / 4元 | $1.2 / 8元 |
| deepseek-v4-pro（DeepSeek-V4-Pro-0813） | 缓存命中输入 | $0.022 / 0.15元 | $0.044 / 0.30元 |
| | 缓存未命中输入 | $0.66 / 4.5元 | $1.32 / 9.0元 |
| | 输出 | $1.98 / 13.5元 | $3.96 / 27.0元 |

以上价格分别来自英文文档 [cite:1195] 与中文文档 [cite:1193]。

- **时段划分**：高峰时段为北京时间周一至周五（不含中国法定节假日）9:00-12:00、14:00-18:00（英文文档表述为 01:00-04:00 和 06:00-10:00 UTC），其余时段（含周末及中国法定节假日全天）为空闲时段；空闲时段价格为高峰时段价格的一半 [cite:1193][cite:1195]。
- **上下文与输出**：两个模型上下文长度均为 1M，最大输出长度 384K [cite:1193][cite:1195]。
- **计费公式**：扣减费用 = token 消耗量 × 模型单价，优先从赠送余额扣减，再扣充值余额 [cite:1193]。
- **旧模型名**：deepseek-v4-flash、deepseek-v4-flash-vision-exp 仍可调用，但对应模型已下线，请求由 DeepSeek-V4.1-Flash 提供服务并按 Flash 价格计费 [cite:1193][cite:1195]。
- **价格变动**：产品价格可能变动，DeepSeek 保留调整价格的权利，建议定期查看官方定价页面 [cite:1193]。

#### 1.2 限流规则

- **并发限制**：deepseek-flash 为 2500，deepseek-v4-pro 为 500 [cite:1193][cite:1195]。
- **限流粒度**：以并发数（并发限制）为核心限流维度，按账号粒度计算，与 API Key 无关；超过并发限度时返回 HTTP 429 错误码 [cite:1191]。
- **细粒度隔离**：用户可通过 user_id 参数实现同一账号下的细粒度隔离（内容安全、KVCache、调度）；普通用户所有 user_id 合并计算并发，提升配额的用户则对每个 user_id 单独限流（deepseek-flash 2500、deepseek-v4-pro 500），超限同样返回 429 [cite:1191]。
- **请求保活**：10 分钟未开始推理则关闭连接 [cite:1191]。
- **RPM/TPM**：官方定价页面未列出 RPM 或 TPM 的具体数值 [unverified]。有第三方来源（NxCode，非官方）称 DeepSeek 不执行严格的 RPM/TPM/并发硬性限制，采用"尽力而为"策略，高峰期可能出现延迟或 503 错误 [cite:1192]，但该说法与官方文档给出的明确并发限制数值（2500/500）不一致，且非官方来源，建议以官方文档为准。

### 二、阿里云百炼平台（Qwen 系列模型）

> 说明：证据材料中**未出现 DeepSeek 系列模型在百炼平台的任何定价或限流数据**，故本节仅覆盖 Qwen 系列 [unverified]。

#### 2.1 定价（每百万 Token，输入/输出）

计费规则：百炼模型调用默认按量计费，部分模型实行阶梯计费，单价取决于单次请求的输入 Token 总量，该请求所有 Token 均按对应阶梯单价结算；K 表示 1,000，M 表示 1,000,000 [cite:1207]。Batch 调用输入输出单价按实时推理价格的 50% 计费，上下文缓存仅输入 Token 享有折扣，两者不能同时生效 [cite:1207]。

**华北 2（北京）地域部分价格** [cite:1207]：

| 模型 | 阶梯 | 输入 | 输出 |
|---|---|---|---|
| qwen3.8-max-prime | 0<Token≤1M | 24 元 | 72 元 |
| qwen3.8-max、qwen3.7-max 系列 | 0<Token≤1M | 12 元 | 36 元 |
| qwen3.6-max-preview | 0<Token≤128K | 9 元 | 54 元 |
| | 128K<Token≤256K | 15 元 | 90 元 |
| qwen3-max | 0<Token≤32K | 2.5 元 | 10 元 |
| | 32K<Token≤128K | 4 元 | 16 元 |
| | 128K<Token≤256K | 7 元 | 28 元 |
| qwen3-max-2025-09-23、qwen3-max-preview | 0<Token≤32K | 6 元 | 24 元 |
| | 32K<Token≤128K | 10 元 | 40 元 |
| | 128K<Token≤256K | 15 元 | 60 元 |
| qwen-max | 无阶梯 | 2.4 元 | 9.6 元 |

**国际（新加坡）地域**价格更高，例如 qwen3.8-max 14.988 元/44.965 元、qwen3.7-max 18.736 元/56.207 元、qwen3-max 8.807 元/44.035 元（0<Token≤32K）等 [cite:1207]。**美国（弗吉尼亚）地域** qwen3.7-max 为 18.736 元/56.207 元，qwen3.8-max 为 12 元/36 元 [cite:1207]。注意：文档价格表为模型调用原价，输入单价不含缓存单价 [cite:1207]。

#### 2.2 限流规则

- **账号维度**：百炼按主账号维度对模型调用设置限流，账号下所有 RAM 子账号、业务空间和 API Key 的调用量合并计算；超出限制时请求被拒绝，通常在一分钟内自动恢复 [cite:1208][cite:1209]。不同模型限流额度相互独立 [cite:1208]。
- **限流维度**：分钟级配额限制（RPM/TPM）、瞬时频率限制（RPS/TPS，即 RPM/60 与 TPM/60）、增速限制（Traffic Burst，阈值随服务状态动态调整）[cite:1211]。
- **报错信息**：触发 RPM 限流报错为 Requests rate limit exceeded / You exceeded your current requests list；触发 TPM 限流报错为 Allocated quota exceeded / You exceeded your current quota；请求频率激增触发系统稳定性保护报错为 Request rate increased too quickly [cite:1208]。
- **超限处理**：限流仅导致超出限制的请求被拒绝（返回 429），免费额度耗尽时返回 403，均不影响已接受请求的生成速度 [cite:1208]。充值不改变默认 RPM/TPM 阈值，限流与计费相互独立；如需更高额度需联系商务经理申请 [cite:1208]。Batch API 调用不受限流限制 [cite:1208]。
- **应对手段**：百炼提供服务端排队等待（请求头 X-DashScope-Wait-Timeout，仅适用于增速/突发限流，不适用于 RPM/TPM 绝对值限流）、提升临时限流额度、PTU、Batch API 等 [cite:1187][cite:1188][cite:1189][cite:1190]。

**华北 2（北京）地域 Qwen 系列限流示例（RPM/TPM，含输入与输出 Token）** [cite:1208]：

| 模型 | RPM | TPM |
|---|---|---|
| qwen3.8-max、qwen3.8-max-0902、qwen3.8-flash | 动态限流（按百炼月消费档位软限流） | — |
| qwen3.7-max | 30,000 | 5,000,000 |
| qwen3.7-max-2026-06-08、qwen3.7-max-2026-05-20 | 600 | 1,000,000 |
| qwen3.7-max-preview、qwen3.7-max-2026-05-17 | 60 | 500,000 |
| qwen3.6-max-preview | 600 | 1,000,000 |
| qwen3-max | 30,000 | 5,000,000 |
| qwen3-max-2026-01-23 | 600 | 1,000,000 |
| qwen3-max-2025-09-23 | 60 | 100,000 |
| qwen3-max-preview | 600 | 1,000,000 |

**新加坡（国际）地域示例** [cite:1209]：qwen3.7-max 600/1,000,000；qwen3.7-max-2026-06-08 与 qwen3.7-max-2026-05-20 60/1,000,000；qwen3.7-max-preview 与 qwen3.7-max-2026-05-17 600/1,000,000；qwen3.6-max-preview 600/1,000,000；qwen3-max 600/1,000,000；qwen3-max-2025-09-23 60/100,000；qwen-max 600/1,000,000；qwen3.7-plus 15,000/5,000,000；qwen3.7-plus-2026-05-26 60/1,000,000。

**动态限流机制**：qwen3.8-max 的 TPM 限流值按账号月消费分档（≤10 万元为 500 万，10 万~100 万元为 1000 万，>100 万元为 2000 万）[cite:1205]。部分模型（如 qwen3.8-max、qwen3.8-flash、deepseek-v4-pro-0813 等）采用动态限流，TPM 限流值随百炼月消费额度分档按月调整，实际可用 TPM 不低于限流值；动态限流下 RPM 限额较高，正常使用不会触发 RPM 限流 [cite:1187][cite:1188][cite:1189][cite:1190]。

**关于并发限制**：证据材料中未给出百炼按量计费模型的明确"并发数"上限指标，限流以 RPM/TPM/RPS/TPS/增速维度表述 [cite:1208][cite:1211]；仅 Token Plan 个人版按套餐档位给出建议 Agent 并发数（Lite 1-2、Essential 2-3、Standard 3-4、Pro 6-8），且该套餐限流阈值动态调整、不支持提升 [cite:1210]。

### 三、ModelScope 平台

关于 ModelScope 平台对 Qwen 和 DeepSeek 系列模型的定价与限流规则，**现有证据材料无法直接证实** [unverified]。

1. **定价方面**：证据材料中仅包含阿里云百炼（Model Studio）平台的 Qwen 系列模型定价信息，例如 qwen3-max 在 0<Token≤32K 区间输入单价为 2.5 元/百万 Token、输出为 10 元/百万 Token，并附有 100 万 Token 免费额度（有效期 90 天）[cite:1202]。但该信息属于阿里云百炼平台，并非 ModelScope 平台，因此不能直接作为 ModelScope 定价的依据。
2. **限流规则方面**：证据材料中同样仅包含阿里云百炼平台的限流规则，例如 qwen3-max 的 RPM 为 30,000、TPM 为 5,000,000，qwen3-max-2025-09-23 的 RPM 为 60、TPM 为 100,000 [cite:1203]。此外，动态限流机制下 qwen3.8-max 的 TPM 限流值按账号月消费分档（≤10 万元为 500 万，10 万~100 万元为 1000 万，>100 万元为 2000 万）[cite:1205]。但这些均属于阿里云百炼或千问 AI 平台，而非 ModelScope。
3. **关于 DeepSeek 系列模型**：证据材料中仅在千问 AI 平台的动态限流档位表中出现 deepseek-v4-pro-0813 和 deepseek-v4.1-flash 的 TPM 限流值 [cite:1205]，未涉及 ModelScope 平台，也未提供其定价信息。

## 未验证结论

以下结论无法被现有引用材料支持，标注为 [unverified]：

1. **DeepSeek 官方 API 的 RPM/TPM 具体数值**：官方定价页面未列出 RPM 或 TPM 的具体数值 [unverified]。第三方来源（NxCode）称 DeepSeek 不执行严格的 RPM/TPM/并发硬性限制，采用"尽力而为"策略，高峰期可能出现延迟或 503 错误 [cite:1192]，但该说法与官方文档给出的明确并发限制数值（2500/500）不一致，且非官方来源，建议以官方文档为准。
2. **ModelScope 平台对 Qwen 和 DeepSeek 系列模型的定价（免费额度、输入/输出价格）和限流规则（RPM/TPM/并发限制）**：现有证据材料均无法证实 [unverified]。
3. **阿里云百炼平台对 DeepSeek 系列模型的定价与限流数据**：所提供的四份证据材料均只覆盖 Qwen（千问）系列及 Token Plan 相关规则，未包含 DeepSeek 系列模型的定价或限流数据 [unverified]。
4. **相同模型（Qwen2.5-72B、DeepSeek-V3）下三者的每百万 token 成本差异**：证据仅提供了通义千问系列（qwen-max、qwen3-max 等）及 DeepSeek 系列在百炼平台的接入方式，但未给出 DeepSeek-V3 在百炼上的具体每百万 token 单价 [cite:1199]；百炼价格文档中列出的均为 Qwen 系列模型价格（如 qwen-max 输入 2.4 元/百万 token、输出 9.6 元/百万 token）[cite:1197]，未包含 Qwen2.5-72B 或 DeepSeek-V3 的定价。DeepSeek 官方 API 与 ModelScope 的定价证据材料中完全没有涉及 [unverified]。间接参考：有报道称阿里云百炼平台曾对 Qwen-Turbo、Qwen-Plus、Qwen-Max 降价，Qwen-Turbo 输入低至每百万 token 0.3 元 [cite:1200]；另有报道提及字节「豆包-1.5-pro」定价为每百万输入/输出 token 0.11/0.28 美元 [cite:1201]，但这些均非目标模型，不能用于回答本子问题。
5. **ModelScope 的限流阈值或超限处理方式**：现有证据材料中未包含相关内容 [unverified]。
